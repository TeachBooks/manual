# Installing and running with Pixi

- Install pixi

In the root file of the TB:

- run `pixi install`

This will install teachbooks and the most common dependecies. 

three tasks:
- `pixi run editor` this will start jupyterlab as the editor for both markdown and jupyternotebooks
- `pixi run serve` starts a server
- `pixi run teachbooks` builds the book (equivalent to `teachbooks build book` as described here)
